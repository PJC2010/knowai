## Rulings

- **R1 — Order and base:** Use `feat/headline-to-hands-on` at the current story-images commit, not the older `main`. Build only the memory prerequisites required by Catch me up during phase one, then reuse them in phase two. Reason: the user's latest ordering and approved base override the earlier plan. Cost if wrong: straightforward branch/reordering work, no deployment impact.
- **R2 — Worktree mechanism:** The exposed native allocator creates disposable per-child worktrees and requires a clean source; this run needs one persistent serial worktree while preserving a dirty source. Use a manually created `.worktrees/headline-to-hands-on`, excluded locally through `.git/info/exclude`, without modifying or stashing the original files. Cost if wrong: manual worktree cleanup, no loss of source edits.
- **R3 — Test corrections:** Use `React.JSX.Element` or inferred return types under React 19. Retention SSR absence checks must match exact `brief-read` class tokens, not `/brief-read/` (which matches existing `brief-reading`). Browser tests clear a number input rather than `fill('abc')`; nonnumeric parsing is tested in unit tests. Saved-depth tests must navigate to `/` without the query after selection, since reload alone merely tests URL state. Do not deliberately fail tests that already protect existing behavior. Cost if wrong: test corrections, not product changes.
- **R4 — Glossary integration:** Use proper paragraph-safe React markup, unique ids, and no dialog role. Never create overlapping hit areas using negative margins. Preserve readable line layout and verify real touch/keyboard behavior; use sufficient line spacing for the specified targets. Preserve source prose in SSR assertions by testing text content excluding popover definitions rather than expecting an uninterrupted raw HTML substring. Cost if wrong: typography adjustments and regression tests.
- **R5 — Prompt links and privacy:** Shared prompt URLs are visible in browser history and can appear in hosting logs. Add that disclosure to Privacy/README as part of H3; do not claim these URLs are secret or that no prompt can ever be present in browser history. Only public story text/static presets generate links; do not add sharing of a reader's typed prompt. Keep textarea content inert; verify no automatic completion even with a mocked connected account. Handle subsequent client-side query navigation without overwriting edits on unrelated rerenders. Cost if wrong: link-state/privacy-copy revision.
- **R6 — Estimator honesty:** Keep raw number input text while typing; use clamped numeric values for calculations and normalize the field on blur. Exclude nonfinite/negative prices and impossible context/output capacities from eligible rankings, with honest unavailable/empty messages and selected-model limitations. Test zero prices, insufficient output limits, saved catalog labeling, and selected models without claiming token capacity proves quality. Cost if wrong: recommendation filtering/copy adjustments.
- **R7 — Catch-up context:** A multi-edition catch-up view must not leave a selected-edition copy action or count masquerading as catch-up data. Hide the edition digest/copy and selected-edition empty/count state while catching up; normal edition behavior returns unchanged. Count each story once, render no featured duplicate, retain keyboard/read/glossary controls, and test multiple edition dates. Describe results as new among available approved stories, not an exhaustive lifetime archive. Cost if wrong: catch-up toolbar adjustments.
- **R8 — Memory robustness:** Validate fields individually for version 1, default the entire object for malformed/unknown versions, dedupe/cap stored ids on load, and handle exactly the 30-minute boundary. No storage access during SSR or preview. Keep update functions stable, avoid I/O inside React state updater functions, and prevent a storage-write failure from undoing in-session changes. Clear success must be truthful; remove failure gets an accessible failure message, and another tab's clear must not resurrect old history. Cost if wrong: storage behavior refinements; browser-only, no database migration.
- **R9 — Documentation accuracy:** H7's claim that nothing stores data is false because Catch me up uses reader memory and linked prompts live in URLs. Document those exceptions and say no automatic model request or server-side reader profile is added. R06 is only partially complete: prompt deep links exist; prompt packs are not claimed complete. Do not publish unverifiable "only site" or competitor-absence claims as product facts. Cost if wrong: documentation revision.
- **R10 — Scoped verification:** Use deterministic fixtures/mocks for acceptance tests, never production credentials or paid completions. Full regression suites run at phase gates; task loops run focused checks first and the task's specified passing checks before commit. Invalid sample tests are replaced with equivalent behavioral assertions, never deleted to get green. Record existing warnings and baseline failures honestly. Cost if wrong: extra validation work.
